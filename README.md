# WarRoom Tactical Scoring System
comprehensive, real-time scoring and telemetry dashboard designed for Red vs. Blue military training exercises. It provides high-level aggregation of unit statistics alongside granular, player-level data, all supported by an integrated AI Retrieval-Augmented Generation (RAG) assistant to answer complex battlefield queries on the fly.

### 🔴 Red vs. 🔵 Blue Scoring
The core of the system tracks live combat metrics between two opposing factions. It provides a real-time overview to score the exercise based on:
* **Active Personnel & Assets:** Live counts of soldiers and vehicles online for both teams.
* **Combat Readiness:** Individual player telemetry tracking ammo counts, GPS connectivity, and health status (Ready, Wounded, Unknown).
* **Casualty Tracking:** Instant updates on killed personnel or destroyed vehicles to determine the dominant force.

### Live AI Assistant (RAG)
The dashboard features an integrated AI advisor powered by Retrieval-Augmented Generation (RAG). By tapping directly into the live exercise data, the assistant allows users to ask natural language questions about the ongoing battle—such as checking specific squad statuses, summarizing team readiness, or locating key assets—and get instant, context-aware answers.

### Player Details View
Granular telemetry for every active participant on the battlefield. Each individual player card displays vital combat statistics, including their unique ID, assigned weapon loadout, live ammo count, GPS connectivity, and current health status (e.g., Ready, Wounded, Unknown)[cite: 2]. Filters and sorting options allow operators to quickly find specific units[cite: 2].

### Settings for Themes
Customizable aesthetic options to fit your command center environment. Easily toggle between different visual themes (like high-contrast tactical displays or sleek dark modes) to ensure the dashboard remains visually optimal and easy to monitor during long exercises.
